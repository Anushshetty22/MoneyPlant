# MoneyPlant Document Style Guide

Use the supplied `MoneyPlant.pdf` as the visual reference for project documents.

## Typography

- Body: Arial
- Main title: Arial Bold, centered
- Section headings: Arial Bold, black
- Emphasis: Arial Italic or Arial Bold Italic
- Code, endpoints, and field names: Roboto Mono

## Page and structure

- A4 portrait pages
- Simple, generous margins
- Centered title block at the beginning
- Numbered major sections
- Numbered steps for procedures
- Bullets for unordered items
- Tables only for genuine field comparisons or status summaries
- No decorative Word themes, colored title rules, or running headers unless specifically requested

## Content style

- Use short explanatory paragraphs.
- Explain what a value means and why it is collected.
- Separate confirmed facts, decisions, assumptions, and pending work.
- Include a clear status and next checkpoint in project documents.
